# La Gran Batalla Barber - Sitio Web Oficial & Motor de Reservas

Plataforma web profesional *mobile-first* desarrollada para **La Gran Batalla Barber** (Itagüí, Colombia).

## Estructura del Proyecto
- `index.html`: Página de inicio con impacto visual, propuesta de valor y llamadas a la acción.
- `nosotros.html`: Historia, misión, visión, valores y equipo de profesionales.
- `servicios.html`: Catálogo interactivo de servicios y **Motor de Reservas Inteligente** con integración simulada de WhatsApp.
- `proyectos.html`: Galería y portafolio de trabajos realizados.
- `contacto.html`: Ubicación dinámica, canales digitales y horarios.
- `css/styles.css`: Estilos personalizados.
- `js/main.js`: Funcionalidades interactivas y menú responsive.
- `robots.txt` y `sitemap.xml`: Optimización SEO técnica.

## Instrucciones de Uso
1. Descomprime el archivo ZIP.
2. Abre `index.html` en cualquier navegador web moderno o publícalo en un hosting estático (Vercel, Netlify, GitHub Pages).
